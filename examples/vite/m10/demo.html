Columns

Selection

Changing mode or the inactive-row policy rebinds the Grid and clears selection, checks and uncommitted edits.

Select first store row and Clear selection change only the active row used by store actions. Set first two eligible selections and Clear selection set change only the selection set.

In multiple mode: click replaces the selection, Ctrl/Meta-click toggles, and Shift-click selects a visible-page range. Focus a row's select button and use Up/Down, Home/End, Shift+navigation or Space.

Independent row checks

Checks do not select a row or edit its Active value. The header checkbox always covers the visible page and shows a mixed state for a partial check.

Validation

Type in the table to see HTML and application validation. Invalid drafts stay outside Rows.

Atomic bulk paste

Select an active row on the visible page first. The sample starts at Email in the default column order and updates two rows. Shift uses its raw numeric code; Active accepts true or false. Double quotes preserve tabs and newlines inside a cell.

Paste follows the current visible row and column order. Phone is protected and still consumes its source position. Readonly and disabled fields behave the same way. Overflow or any invalid cell rejects the entire paste. You can also paste plain text directly into a bound table field.
