## 목적
Natural-JS v2.0 모듈 분리 및 tsup 빌드 시스템 구축: 8개 큰 파일을 60개 작은 모듈로 분리하고, NC/NA/ND/NU/NUS를 단일 N 네임스페이스로 통합하며, Shell 스크립트를 tsup 빌드로 전환한다.

## 선행 절차(필수)
- 본 작업은 **진행 전 반드시** `project-0-natural_js-shrimp-task-manager-plan_task` 툴로 작업계획을 수립한 뒤, 그 계획을 기준으로 단계별로 수행한다.
- 작업 계획 수립 시 `docs/working/module-restructuring/final-proposal.md`와 `FINAL-CHANGELOG.md`를 참조한다.

## 작업 컨텍스트(반드시 준수)
- **대상 파일**: `src/*.js` (8개 메인 파일 → 60개 모듈)
- **제약**: ES5+ 호환, jQuery 3.7.1 의존성 유지, 새 외부 의존성 추가 금지
- **빌드 툴**: Shell 스크립트 제거, tsup(esbuild 기반) 도입
- **타입 검증**: `@types/index.d.ts` 통합 및 NC/NA/ND 타입 제거
- **참조 문서**: `docs/working/module-restructuring/final-proposal.md`, `FINAL-CHANGELOG.md`

## 목표(성공 기준)
- **모듈 분리**: 8개 파일(총 12,775 lines) → 60개 모듈(평균 150 lines)
- **네임스페이스 통합**: NC/NA/ND/NU/NUS 완전 제거 → N.xxxx로 단일화
- **빌드 시스템**: `compiler/*.sh` 제거 → tsup으로 전환(빌드 시간 30초 → 1초)
- **산출물**: dist/ 내 CJS/ESM/IIFE 번들 생성(natural.js, natural.mjs, natural.min.js, natural.es5.min.js)
- **API 유지**: jQuery 확장 사용법(`N("#id").form()`) 동일하게 유지
- **마이그레이션 도구**: `scripts/migrate-to-n.js` 제공

## 비목표(하지 말 것)
- jQuery 완전 제거(DOM 조작/이벤트는 jQuery 계속 사용)
- 공개 API 변경(기존 사용자 코드 호환성 유지)
- NC/NA/ND 하위 호환성 유지(Proxy 등 사용하지 않음, 완전 제거)
- 성능 최적화(동작 호환성 우선)

import * as StringUtils from './core/utils/string.js';
import * as DateUtils from './core/utils/date.js';

export class NJS extends jQuery {

    }

    form(options) { return new Form(this, options); }
    grid(options) { return new Grid(this, options); }
    // ... 모든 컴포넌트

    // Core Utilities
    static string = StringUtils;
    static date = DateUtils;
    // ... 모든 유틸리티
    
    // Type Checking

    static isString = TypeChecker.isString;
    // ... 모든 타입 체커
    
    // Logger
    static debug = Logger.debug;
    static log = Logger.log;
    // ... 모든 로거
    
    // Architecture
    static comm = (obj, url) => new Comm(obj, url);
    static cont = (obj, contObj) => new Cont(obj, contObj);
    // ... 모든 아키텍처 기능
    
    // Data, UI, UI Shell, Code, Template
    // ...
}

export function N(selector, context) {
    return new NJS(selector, context);
}

// Copy static properties to N function
Object.keys(NJS).forEach(key => {
    if (key !== 'prototype' && key !== 'length' && key !== 'name') {
        N[key] = NJS[key];
    }
});

// Global export
if (typeof window !== 'undefined') {
    window.N = N;
}

## 주의(중요)
- **jQuery 의존성 제거는 하지 말 것**: DOM 조작/이벤트는 jQuery 계속 사용
- **NC/NA/ND 하위 호환성 없음**: Proxy 등 사용하지 않고 완전 제거 (Breaking Change)
- **사용법 동일 유지**: `N("#id").form()` 같은 jQuery 확장은 그대로
- **ES5 빌드는 별도**: tsup.config.es5.ts로 별도 실행
- **Watch 모드 활용**: `npm run dev`로 개발 시 0.3초 리빌드
- **compiler 폴더 제거**: 레거시 컴파일 구조 완전 제거
