JSdoc 타입 안내

TypeScript를 사용하지 않는 페이지에서도 jsdoc으로 타입 힌트를 제공합니다.

/** @typedef {{ id:string, name:string, email:string }} User */

/**
 * @param {User} user
 * @returns {string}
 */
function formatUser(user) {
  return `${user.name} <${user.email}>`;
}

TS를 사용할 경우 tsconfig.json에 \"types\": [\"js/natural_js/@types\"]를 추가하세요.
