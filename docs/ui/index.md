# Concepts

* [Natural-UI component model](component-model.md) - Rules shared by every Natural-UI component - construction forms, plugin return values, instance storage, option precedence, global event handlers and the data-bound API.
* [N.alert](alert.md) - Shows a message dialog (alert or confirm) as a layer over the window or an element, or a tooltip message next to an input element.
* [N.button](button.md) - Styles a, button and input[type=button] elements as buttons (size, color, type) and toggles their enabled or disabled state.
* [N.datepicker](datepicker.md) - Opens a calendar panel under a text input for picking a date (or a year and month with monthonly) and writes the digits into the input.
* [N.form](form.md) - Binds one row of a JSON object array to the id-matched elements inside a block element, with two-way sync, rowStatus tracking, formatting and validation.
* [N.grid](grid.md) - Renders a JSON object array as tbody rows of a table template with id-based binding, fixed header or list layout, selection, sorting, filtering and rowStatus.
* [N.list](list.md) - Renders a JSON object array as li rows of a ul template with id-based two-way binding, row selection, checkboxes, scroll paging and rowStatus tracking.
* [N.pagination](pagination.md) - Builds page index links for a client-side data array or a server-side total row count and reports each page change with its rows and paging numbers.
* [N.popup](popup.md) - Opens a layer popup built on N.alert, either from an element of the current page or from a separately loaded page with its own Controller.
* [N.select](select.md) - Binds a JSON object array to a select, select[multiple], radio or checkbox element as options or generated inputs, and gets or sets the selection; also covers the CSS-only Switch.
* [N.tab](tab.md) - Turns a div containing a ul of tab items and content divs into a tab view, optionally loading each tab's content page with its own Controller.
* [N.tree](tree.md) - Builds a collapsible ul/li tree from a flat JSON object array in which each row names its parent, with node selection and optional cascading checkboxes.
* [Theming](theming.md) - How Natural-UI styles are themed - design tokens in tokens.css, Material Design 3 color roles in light.css and dark.css, and the class conventions of natural.ui.css. (draft)
