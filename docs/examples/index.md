# Concepts

* [Edit form data](edit-form-data.md) - Block page that loads a record into an N.form, detects edits through rowStatus, and sends the updated row with an N.comm PATCH request after confirmation.
* [Enter form data](enter-form-data.md) - Block page that creates a new row with N.form add(), validates it, asks for confirmation with N.alert and posts it with N.comm, with a revert button.
* [Grid CRUD (fixed header)](grid-crud-fixed-header.md) - Block page with a search form and a fixed-header N.grid (height above 0, multi-row header) that adds, deletes, validates and saves changed rows in one request.
* [Grid CRUD (list type)](grid-crud-list-type.md) - Block page with a search form and a list-type N.grid (height 0, resizable columns) that adds, deletes, validates and saves changed rows in one request.
* [Retrieve a data list](retrieve-data-list.md) - Block page that validates an N.form search box and loads the matching rows from the server into a sortable, filterable fixed-header N.grid.
* [Retrieve form data](retrieve-form-data.md) - Block page that loads one record through N.comm and shows it read-only in an N.form bound to td and img elements, with data-format rules.
