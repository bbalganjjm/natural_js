# Concepts

* [Template: search form + grid](search-grid.md) - Natural-TEMPLATE screen with a search form bound to common codes, a fixed-header grid with header filters and a search button, declared with p., c. and e. properties.
* [Template: search form + grid (CRUD)](search-grid-crud.md) - Natural-TEMPLATE screen that retrieves rows into an editable grid, adds, deletes and saves them, and fills a row field from a department popup opened by a row button.
* [Template: search form + grid + detail form (horizontal)](search-grid-detail-horizontal.md) - Natural-TEMPLATE master-detail screen where selecting a grid row binds it into a detail form beside the grid; both share one data set for add, delete, reset and save.
* [Template: search form + grid + detail form (vertical)](search-grid-detail-vertical.md) - Vertical variant of the Natural-TEMPLATE master-detail screen, with the detail form below the grid and p.select declared in object form with default selections.
* [Template: search form + grid + paging](search-grid-paging.md) - Natural-TEMPLATE screen that pages search results on the server with N.pagination, sending the search row plus the page numbers and redrawing the links from totalCount.
