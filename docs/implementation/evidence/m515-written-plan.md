# Decisions

- Framework source, public types, dependencies and entries remain unchanged unless a concrete uncovered caller justifies a separate minimal correction.
- Application projection uses native functions next to its real use; no public convenience utility or optional helper package is created.
- Own enumerable object values and indexed arrays follow actual Rows traversal. A stored undefined value is invalid; omitted and nullable values remain deliberate schema choices.
- Raw business metadata is not Rows state. Existing state descriptors explicitly carry pending statuses; wire serialization deliberately names its own operation field.
- Ordinary array filter/sort and existing Grid/List view methods preserve useful filtering/order outcomes. Use Rows.move for store order and domain array.sort only when the application intends external mutation.
